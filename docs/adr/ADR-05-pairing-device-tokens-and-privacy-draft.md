# ADR-05：同源配对、设备令牌与日志隐私（草案）

状态：草案（IMP-04 完善）
日期：2026-09-17

## 背景

家庭成员通过 PWA 控制音乐，需要轻量的设备配对与身份；同时原始录音、
转写文本与行为数据涉及隐私，必须默认最小化。

## 决定（草案）

1. **配对**：管理员在受控入口生成一次性配对码（短期有效）；PWA 提交配对码
   后获得 `device_id` + 设备令牌（可撤销）。成员昵称只用于偏好范围。
2. **传输与认证**：家庭内使用受信 HTTPS 入口（caddy 已部署）；PWA 全部请求
   同源 `/api/v1/*`，会话 Cookie 为 Secure/HttpOnly/SameSite；写操作校验
   Origin。设备入口使用设备令牌（非 HA/MA 管理员凭据）。
3. **设备身份**：`devices.device_id` 与命令幂等约束的 `device_id` 一致；
   令牌只存哈希。
4. **隐私默认值**：默认不持久保存原始录音；转写文本保留期 14 天（可配置）；
   配对令牌与完整录音不进入诊断导出。
5. **测试**：未配对读写被拒；配对后可控制；撤销令牌后设备立即失效。
